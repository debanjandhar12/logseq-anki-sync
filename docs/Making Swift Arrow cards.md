Swift cards are very easy to create (hence "swift") and meant to be used for learning description or characteristics of a topic. It is highly recommended to use it with the option `includeParentContent` enabled (disabled by default, go to plugin settings to enable).

They can be created with the syntax: `:->` or `:<-` or `:<->`. The direction of arrow denote the direction of test.
**For Example,**
```md
Tuberculosis
```
- ```md
  Description :-> It is a potentially serious infectious disease that mainly affects the lungs.
  ```
- ```md
  Symptoms :-> pain in the chest, chronic cough, fatigue, fever, loss of appetite
  ```
