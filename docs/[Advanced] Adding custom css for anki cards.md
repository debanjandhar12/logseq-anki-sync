Currently, custom css can be added through Anki UI.
Steps:
- Open Anki.
- Click `Tools` -> `Manage Note Types` -> `Select the note type generated by plugin (named "your logseq graph name + Model") -> `Cards`
- Go to css tab and edit the textbox with your css.
