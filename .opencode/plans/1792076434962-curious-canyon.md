# E2E Test Architecture Refactoring Plan

## Overview

Refactor e2e tests to use a simpler `beforeAll`/`afterAll` pattern instead of the heavy `createLogseqGraphFixture` approach, while enabling permanent page deletion (no more `Date.now()` suffixes needed).

## User Requirements

1. **Scenario tests** (7 files in `tests/scenario/ai-chat-modal/`): Replace fixture-based setup with beforeAll/afterAll hooks
2. **Existing command tests** (20+ files): Replace Date.now() names with fixed names, remove 300ms waits, use permanent deletion
3. **Delete unused helper files** if no longer needed

## Phase 1: Create Cleanup Helper

### File: `tests/helpers/logseq/deletePagePermanently.ts` (NEW)

A simple utility for guaranteed page cleanup:

```typescript
import type {EntityID} from "@logseq/libs/dist/LSPlugin";

type PermanentDeleteEditor = typeof logseq.Editor & {
    deleteRecycledPagePermanently(page: EntityID): Promise<boolean | null>;
};

/** Delete page and permanently remove from recycle bin. */
export async function deletePagePermanently(name: string): Promise<void> {
    const page = await logseq.Editor.getPage(name);
    if (!page) return;

    // Soft delete
    await logseq.Editor.deletePage(page.uuid);

    // Wait for recycle bin
    await sleep(1000);

    // Permanent delete
    const editor = logseq.Editor as PermanentDeleteEditor;
    if (typeof editor.deleteRecycledPagePermanently === "function") {
        await editor.deleteRecycledPagePermanently(page.uuid);
    }

    // Wait for UUID to disappear
    await sleep(1000);
}

function sleep(ms: number) {
    return new Promise(resolve => setTimeout(resolve, ms));
}
```

### Pattern for command tests

**Before:**
```typescript
const pageName = "CreatePageCommandTestPage_" + Date.now();
const waitForLogseqDb = () => new Promise((resolve) => setTimeout(resolve, 300));

beforeAll(async () => {
    const existingPage = await logseq.Editor.getPage(pageName);
    if (existingPage) {
        await logseq.Editor.deletePage(pageName);
        await waitForLogseqDb();
    }
    page = await logseq.Editor.createPage(pageName, {}, {redirect: false, createFirstBlock: true});
    await waitForLogseqDb();
}, 60_000);

afterAll(async () => {
    await logseq.Editor.deletePage(pageName);
    await waitForLogseqDb();
}, 60_000);
```

**After:**
```typescript
// Use kebab-case with descriptive prefix
const pageName = "test-create-page-command";

beforeAll(async () => {
    await deletePagePermanently(pageName);
    page = await logseq.Editor.createPage(pageName, {}, {redirect: false, createFirstBlock: true});
}, 60_000);

afterAll(async () => {
    await deletePagePermanently(pageName);
}, 60_000);
```

### Block deletion before page deletion

For tests that create blocks:

```typescript
const pageName = "TestPage";
let pageBlock: BlockEntity;

beforeAll(async () => {
    await deletePagePermanently(pageName);
    const created = await logseq.Editor.createPage(pageName, {});
    pageBlock = created!;
});

afterAll(async () => {
    // Delete child blocks first
    const children = await logseq.Editor.getPageBlocksTree(pageBlock.uuid);
    for (const child of children.reverse()) {
        await logseq.Editor.removeBlock(child.uuid);
    }
    await deletePagePermanently(pageName);
}, 60_000);
```
