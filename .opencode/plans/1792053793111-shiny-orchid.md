# Test Architecture Simplification Plan

## Context

Commit 14e4bdfb introduced scenario-based testing infrastructure. While well-designed, certain components are overly complex and could benefit from simplification via external libraries or better code organization.

## Goals

1. Replace custom implementations with battle-tested libraries where possible
2. Split oversized helpers into smaller, focused modules
3. Add missing type definitions for better discoverability
4. Extract repeated patterns into reusable helpers

## Phase 1: Replace `throttleLogseqRequests.ts` with `async-lock`

**Current State:**
- 63-line custom implementation using Browser Lock API + Promise queue
- Enforces 100ms minimum interval between Logseq API requests

**Proposed Change:**
Replace with `async-lock` (already in dependencies, no new dependency):

```typescript
import AwaitLock from "async-lock";

const lock = new AwaitLock();
const LOGSEQ_REQUEST_INTERVAL_MS = 100;

const queueByFetch = new WeakMap<typeof globalThis.fetch, {tail: Promise<void>; nextStartAt: number}>();

export function throttleLogseqRequests(logseqApiUrl: string): void {
    const originalFetch = globalThis.fetch;
    if (queueByFetch.has(originalFetch)) return;

    const queue = {tail: Promise.resolve(), nextStartAt: 0};

    const queuedFetch: typeof fetch = async (input, init) => {
        const requestUrl =
            typeof input === "string" ? input : input instanceof URL ? input.href : input.url;
        if (requestUrl !== logseqApiUrl) return originalFetch(input, init);

        return lock.acquire(LOGSEQ_REQUEST_LOCK_NAME, async () => {
            const delay = Math.max(0, queue.nextStartAt - Date.now());
            if (delay > 0) await new Promise((resolve) => setTimeout(resolve, delay));
            const requestStartedAt = Date.now();
            queue.nextStartAt = requestStartedAt + LOGSEQ_REQUEST_INTERVAL_MS;
            return originalFetch(input, init);
        });
    };

    queueByFetch.set(originalFetch, queue);
    globalThis.fetch = queuedFetch;
}
```

**File:** `tests/helpers/logseq-proxy-wrapper/throttleLogseqRequests.ts`

**Rationale:** `async-lock` is already in dependencies. This reduces 63 lines to ~15 lines with no new maintenance burden.

## Phase 3: Extract Viewport & Timing Helpers

### 3.1 Create `tests/helpers/chat-scenario/viewport.ts`

**Problem:** Viewport resize loops are repeated in `composer-ui.e2e.test.tsx` and `thread-list-ui.e2e.test.tsx`:
```typescript
for (const [width, height] of [
    [1280, 720],
    [640, 720],
    [640, 600],
    [1280, 720]
]) {
    await page.viewport(width, height);
    await expect.poll(() => { /* verify layout */ }).toBe(true);
}
```

**Proposed Solution:**
```typescript
export interface ViewportSize {
    width: number;
    height: number;
}

export const COMMON_VIEWPORTS: ViewportSize[] = [
    {width: 1280, height: 720},
    {width: 640, height: 720},
    {width: 640, height: 600}
];

export async function withViewports(
    viewports: ViewportSize[],
    callback: (size: ViewportSize) => Promise<void>
) {
    for (const size of viewports) {
        await page.viewport(size.width, size.height);
        await callback(size);
    }
    await page.viewport(1280, 720); // Reset
}
```

**File:** `tests/helpers/chat-scenario/viewport.ts`

### 3.2 Create `tests/helpers/chat-scenario/timing.ts`

**Problem:** Animation frame waiting pattern is repeated:
```typescript
await new Promise<void>((resolve) =>
    requestAnimationFrame(() => requestAnimationFrame(() => resolve()))
);
```

**Proposed Solution:**
Use `raf` package (lightweight ~100 bytes) or Playwright's built-in evaluation:

```typescript
import raf from "raf";

export async function waitForAnimationFrames(count: number = 2): Promise<void> {
    return new Promise((resolve) => {
        let frames = 0;
        const tick = () => {
            frames++;
            if (frames >= count) {
                raf(() => resolve());
            } else {
                raf(tick);
            }
        };
        raf(tick);
    });
}

// Alternative using Playwright's page.evaluate:
export async function waitForAnimationFrames(count: number = 2): Promise<void> {
    await page.evaluate((n) => {
        return new Promise<void>((resolve) => {
            let frames = 0;
            const tick = () => {
                frames++;
                if (frames >= n) resolve();
                else requestAnimationFrame(tick);
            };
            requestAnimationFrame(tick);
        });
    }, count);
}
```

**Decision:** Use Playwright's `page.evaluate()` approach - no new dependency needed.

**File:** `tests/helpers/chat-scenario/timing.ts`

## Phase 4: Extract Branching/Tracker Assertions

### 4.1 Create `tests/helpers/chat-scenario/assertions/trackerAt.ts`

**Problem:** `trackerAt()` function is defined inline in `advanced-branching.e2e.test.tsx` but could be reusable.

**Proposed:**
```typescript
import type {ExportedMessageRepository} from "@assistant-ui/react";
import {findLastLogseqReversibleTransactionTracker} from "../../../src/chat-app/tools/transaction/getLastLogseqReversibleTransactionTracker";

export interface TrackerLocation {
    messageId: string;
    toolCallId: string;
}

export interface TrackerWithLocation {
    tracker: ReturnType<typeof findLastLogseqReversibleTransactionTracker>;
    location: TrackerLocation;
}

export function trackerAt(
    repository: ExportedMessageRepository,
    location?: TrackerLocation
): TrackerWithLocation {
    const messages = location
        ? repository.messages
              .filter(({message}) => message.id === location.messageId)
              .map(({message}) => {
                  if (message.role !== "assistant")
                      throw new Error("Tracker artifacts must belong to assistant messages");
                  return {
                      ...message,
                      content: message.content.filter(
                          (part) =>
                              part.type === "tool-call" && part.toolCallId === location.toolCallId
                      )
                  };
              })
        : repository.messages.map(({message}) => message);
    const located = findLastLogseqReversibleTransactionTracker(messages);
    expect(located, "The real tool must persist its transaction artifact").not.toBeNull();
    return {tracker: located!, location: location!};
}
```

**File:** `tests/helpers/chat-scenario/assertions/trackerAt.ts`
