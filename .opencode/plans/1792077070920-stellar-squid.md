# E2E Test Refactoring Plan

## Context

The project has two categories of e2e tests that need refactoring to:
1. Use a **consistent approach** across all e2e test files (beforeAll/afterAll)
2. Replace Date.now() page names with **fixed names** for better test isolation
3. Replace 300ms wait patterns with **proper polling**
4. Use **permanent deletion** (deleteRecycledPagePermanently) for proper cleanup

## Design Decision: Unified beforeAll/afterAll Approach

All e2e test files will use the same pattern:
- **Before:** Import helper functions, use beforeAll/afterAll for setup/teardown
- **Cleanup:** Use `deletePagePermanently` for pages, `deleteBlockPermanently` for blocks
- **Fixed names:** No Date.now() suffixes - use static string constants
- **Polling:** Replace setTimeout waits with proper condition polling

This ensures:
1. All test files look similar and are easy to understand
2. Test isolation is improved with fixed names
3. Cleanup is complete (permanent deletion, not just soft delete)
4. No flaky tests due to arbitrary sleep times

## 1. New Helper Files to Create

### 1.1 `tests/helpers/logseq/deletePagePermanently.ts`

```typescript
import type {EntityID, PageIdentity} from "@logseq/libs/dist/LSPlugin";
import {isPageSoftDeleted} from "../../../src/core/logseq-reversible-transaction-tracker/commands/utils/isPageSoftDeleted";
import {LogseqEditor} from "../../../src/logseq/LogseqEditor";

type PermanentDeleteEditor = typeof logseq.Editor & {
    deleteRecycledPagePermanently(page: PageIdentity | EntityID): Promise<boolean | null>;
};

async function waitForCondition(
    condition: () => Promise<boolean>,
    timeoutMs: number = 10_000,
    intervalMs: number = 50
): Promise<void> {
    const deadline = Date.now() + timeoutMs;
    while (Date.now() < deadline) {
        if (await condition()) return;
        await new Promise((resolve) => setTimeout(resolve, intervalMs));
    }
    throw new Error("Timed out waiting for condition");
}

/**
 * Permanently deletes a page by first soft-deleting it (if needed),
 * then permanently deleting it from the recycle bin.
 */
export async function deletePagePermanently(pageName: string): Promise<void> {
    const page = await LogseqEditor.getPage(pageName);
    if (!page) return;

    if (!isPageSoftDeleted(page)) {
        const result = await logseq.Editor.deletePage(pageName);
        if (result === false) return;
        await waitForCondition(async () => {
            const current = await LogseqEditor.getPage(pageName);
            return !current || isPageSoftDeleted(current);
        });
    }

    const editor = logseq.Editor as PermanentDeleteEditor;
    if (typeof editor.deleteRecycledPagePermanently !== "function") {
        throw new Error("Editor.deleteRecycledPagePermanently is unsupported");
    }

    await editor.deleteRecycledPagePermanently(page.uuid);
    await waitForCondition(async () => !(await LogseqEditor.getPage(pageName)));
}

/**
 * Permanently deletes a page by UUID.
 */
export async function deletePagePermanentlyByUuid(pageUuid: string): Promise<void> {
    const page = await LogseqEditor.getPage(pageUuid);
    if (!page) return;

    if (!isPageSoftDeleted(page)) {
        const result = await logseq.Editor.deletePage(pageUuid);
        if (result === false) return;
        await waitForCondition(async () => {
            const current = await LogseqEditor.getPage(pageUuid);
            return !current || isPageSoftDeleted(current);
        });
    }

    const editor = logseq.Editor as PermanentDeleteEditor;
    if (typeof editor.deleteRecycledPagePermanently !== "function") {
        throw new Error("Editor.deleteRecycledPagePermanently is unsupported");
    }

    await editor.deleteRecycledPagePermanently(pageUuid);
    await waitForCondition(async () => !(await LogseqEditor.getPage(pageUuid)));
}
```

## 2. Scenario Test Refactoring

### 2.1 All 7 Files - Convert to beforeAll/afterAll Pattern

All scenario tests currently use `aiChatScenarioFixture.test` which includes the heavy `graph` fixture. The goal is to:

1. **Remove the `graph` fixture dependency** from the test
2. **Use beforeAll/afterAll hooks** for graph setup when needed
3. **Import and use helpers** for cleanup

#### Pattern for scenario tests:

**Before (current):**
```typescript
import {test} from "../../helpers/chat-scenario/fixtures/aiChatScenarioFixture";

test("some test", async ({chat, model, graph, storage}) => {
    // test uses graph.createPage, graph.preparePage, etc.
});
```

**After (new pattern):**
```typescript
import {afterAll, beforeAll, describe, expect, it} from "vitest";
import {deletePagePermanently} from "../../helpers/logseq/deletePagePermanently";

const PAGE_NAME = "test-ai-chat-fixed-page";

describe("Test Suite", () => {
    beforeAll(async () => {
        await deletePagePermanently(PAGE_NAME);
        // Setup code...
    }, 60_000);

    afterAll(async () => {
        await deletePagePermanently(PAGE_NAME);
    }, 60_000);

    it("some test", async () => {
        // test code...
    });
});
```

### 2.3 Example Refactoring: `basic-branching.e2e.test.tsx`

This is the simplest case - no tests actually use the graph fixture directly.

**Changes:**
1. Remove import of `aiChatScenarioFixture.test`
2. Use standard `test` from vitest
3. Add beforeAll/afterAll for chat mount/unmount
4. Keep `chat.mount()` and `chat.unmount()` per-test

**New structure:**
```typescript
import {afterAll, beforeAll, describe, expect, test} from "vitest";

```

### 2.4 Example Refactoring: `advanced-branching.e2e.test.tsx`

This is the most complex case - heavy graph usage.

**Changes:**
1. Add beforeAll/afterAll for page setup/cleanup
2. Use `deletePagePermanently` for cleanup
3. Create pages in beforeAll, track UUIDs
4. Clean up all pages in afterAll

```typescript
const P = "test-ai-chat-advanced-p";
const Q = "test-ai-chat-advanced-q";

describe("Advanced branching", {timeout: 60_000}, () => {
    let pUuid: string;
    let qUuid: string;

        qUuid = qPage!.uuid;
    }, 60_000);

    afterAll(async () => {
        await deletePagePermanently(P);
        await deletePagePermanently(Q);
    }, 60_000);

    // Tests use pUuid and qUuid...
});
```

```typescript
const pageName = "TestPage_" + Date.now();
const waitForLogseqDb = () => new Promise((resolve) => setTimeout(resolve, 300));

beforeAll(async () => {
    const existingPage = await logseq.Editor.getPage(pageName);
    if (existingPage) {
        await logseq.Editor.deletePage(pageName);
        await waitForLogseqDb();
    }
    page = await logseq.Editor.createPage(pageName, {}, {...});
    await waitForLogseqDb();

    await logseq.Editor.deletePage(pageName);
```

#### Tag/Property Tests
Use deleteTagPermanently:
