# AI-Generated Thread Titles

New chat threads receive a concise title generated by the same model selected for the chat. Reusing the selected model and placing the original user message first allows providers to reuse prompt-prefix caches where supported.

## Request Data

Title generation sends exactly two user messages to the model:

1. The text parts of the thread's first user message.
2. An instruction to return only a concise thread title.

The request does not include attachments, later conversation messages, the assistant response, the main system prompt, tools, or reasoning settings.

## Output And Fallback

Generated output is normalized by removing common labels, quotes, Markdown wrappers, extra whitespace, and trailing punctuation. Titles are limited to 50 Unicode characters.

If the first user message has no text, no model is selected, provider configuration is invalid, generation fails, or the output is unusable, the title is:

```text
New Chat (<thread-id>)
```

## Generation Lifecycle

assistant-ui automatically requests a title once for a newly initialized thread, after its first model run ends. It does not automatically retry a failed request or regenerate after later messages.

The assistant-ui API can still request title generation explicitly. An explicit request generates a new title using the model selected at that time and can overwrite the existing title.
